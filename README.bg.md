# Ezik — Персонализирано приложение за учене на езици (Reels стил)

🇬🇧 [English](README.md) · 🇧🇬 Български

**Ezik** е уеб приложение с отворен код (Next.js 15 PWA + Python Content Factory + Supabase/PostgreSQL) за учене на език от абсолютна нула до средно напреднало ниво (`A0 → A1 → A2 → B1 → B2`) чрез вертикална лента от интерактивни карти като в Reels / TikTok (`scroll-snap-type: y mandatory`).

Всяка карта се решава за **8–15 секунди**, комбинира **реални лицензирани снимки**, **невронно испанско аудио** с нормална (`1.0x`) и бавна (`0.75x` 🐢) скорост, **рентгенов речник при докосване на всяка дума** (`XRaySheet`) и научно доказания алгоритъм за дългосрочна памет **FSRS v5 (`ts-fsrs`)**.

---

## ✨ Основни възможности

- **Вертикална Reels лента (`/`):** Пълноекранни интерактивни карти с 10 педагогически формата:
  1. `sound_rule` — Правила за четене и произношение с аудио примери.
  2. `visual_word` — Визуална дума със снимка, цветен род (`el` в синьо, `la` в коралово), когнат и мини-изречение.
  3. `phrase_situation` — Житейска ситуация (кафене, летище, хотел, запознанство).
  4. `micro_builder` — Магнитни блокчета за сглобяване на изречение с докосване.
  5. `diglot_weave` — Мостови изречения (английски контекст с вплетени испански думи).
  6. `story_xray` — Кратка 3-изреченска история с интерактивен рентген на всяка дума.
  7. `audio_blur` — Слухово разпознаване със замъглен текст, който се разкрива при отговор.
  8. `say_it` — Активно изговаряне на глас (с Web Speech разпознаване `es-ES` или самооценка).
  9. `shadowing` — Синхронно повтаряне с караоке подсветка по думи (`word_timings`).
  10. `trap_choice` — Чести капани за начинаещи (`ser` vs `estar`, фалшиви приятели, изключения в рода).
- **Рентген на всяка дума (`XRaySheet`):** Докосването на която и да е испанска дума отваря долен панел с произношение, превод на английски и български, езиков мост (`bg_bridge`), аудио (`1x` и `0.75x`) и бутон `✓ I already know this`.
- **6-степенна спирала на повторение + FSRS v5 памет:** Всяка дума или фраза се появява в **6 различни формата на карта** (`Step 1/6 ●○○○○○` → `Step 6/6 ●●●●●●`), разделени с по 2–3 други думи помежду им, преди да се премине напред. Сбъркана дума се връща веднага след няколко карти в нов формат, а дългосрочният преговор се планира според силата на паметта (`0–5` чертички).
- **Учебна карта с 40 пакета от A0 до B2 (`/today`):** Структурирана програма от Пакет 01 (`A0`) до Пакет 40 (`B2`) с табове за филтриране по CEFR ниво (`ALL`, `A0`, `A1`, `A2`, `B1`, `B2`), автоматично отключване при 75% покритие и свободен избор на пакет по всяко време.
- **Личен речник (`/words`):** Търсене, филтриране по статус (`all`, `learning`, `due`, `mastered`), индикатор за сила `0–5`, аудио и бързо маркиране на вече познати думи.

## 🚀 Бърз старт (Как всеки може да го пусне локално)

### 1. Изисквания
- **Node.js 20+** и `npm`
- **Python 3.12+** и [`uv`](https://docs.astral.sh/uv/) (за Python worker-а)
- **Supabase** проект (облачен или self-hosted PostgreSQL с PostgREST)

### 2. Настройка на базата данни и `.env`
1. Изпълнете SQL миграцията [`database/migrations/001_ezik_app_init.sql`](database/migrations/001_ezik_app_init.sql) във вашия Supabase SQL Editor.
2. Копирайте `.env.example` като `.env` в корена на проекта и попълнете вашите ключове:
   ```bash
   cp .env.example .env
   ```
   Минимално необходими са `SUPABASE_URL`, `SERVICE_ROLE_KEY` и `SESSION_SECRET`.
3. Създайте потребител в таблицата `ezik_app_users` (напр. през SQL Editor с `bcrypt` хеш на паролата).

### 3. Захранване на учебната програма, снимките и аудиото (по избор)
Базовите снимки и аудио файлове за Пакети 01–05 вече са включени в `apps/web/public/`. За да захраните вашата база данни или да генерирате нови пакети:
```bash
cd services/worker
uv run worker seed-curriculum
uv run worker fetch-images --force --limit 100
uv run worker generate-audio --limit 100
uv run worker generate-cards
```

### 4. Стартиране на уеб приложението
```bash
cd apps/web
npm install
npm run dev
```
Отворете `http://localhost:3006` (или порта, на който сте го пуснали).

## 🌍 Добавяне на нови езици

Испанският е само първият курс. **Можете да добавите какъвто език искате — просто кажете на своя ИИ да го добави.**

Отворете проекта в своя ИИ асистент за програмиране (Claude Code, Cursor, Codex, Gemini CLI и др.) и напишете например:

> „Добави италиански като нов език за учене, със същата структура от 40 пакета (A0–B2) като испанския, и генерирай снимките, аудиото и картите за него.“

Архитектурата е готова за това:
- Всички основни таблици (`ezik_app_packs`, `ezik_app_items`, `ezik_app_cards`, `ezik_app_settings`) имат колона `target_lang`.
- Новите пакети се добавят в `services/worker/src/ezik_worker/curriculum.py` с кода на езика, а worker-ът намира снимки, генерира аудио и създава картите.
- `SPEC.md` описва подробно форматите на картите и методиката, така че вашият ИИ има всичко нужно, за да следва същия подход.

Същото важи и за помощния език: сега испанският се обяснява през английски и български, но можете да помолите своя ИИ да го смени с вашия роден език.

## 🛠️ Как да развивате и подобрявате проекта

- **Добавяне на нови думи и пакети с ИИ:** Използвайте `uv run worker seed-curriculum --ai-pack es_06 --count 25 --max-usd 1.00`, след което пуснете `fetch-images`, `generate-audio` и `generate-cards`.
- **Пускане на тестовете:**
  - Python worker: `cd services/worker && uv run --extra dev pytest -q`
  - Next.js фронт-енд билд и типове: `cd apps/web && npm run build`
